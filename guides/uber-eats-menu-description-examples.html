How these examples are written

Each "after" is 140 to 260 characters, Uber's own advice for menu descriptions (Uber). Each one says what the dish is, names the main ingredients, adds one detail that makes it yours, and answers a question before it's asked: the size, the spice level or what comes with it. Make them yours

  • Use the dish names your customers know, then explain them.
  • Only list ingredients that are really in the dish.
  • Say sizes and piece counts exactly.
  • Mark vegetarian, vegan or gluten free only when it's true.

Questions

How long should an Uber Eats menu description be?

Uber's advice is 140 to 260 characters, about two short sentences.

What makes a good menu description?

What the dish is, its main ingredients, one detail that makes it yours, and anything people need to know before ordering, like size, spice level or what comes with it.

Can I copy these examples?

Yes, as a starting point. Change the ingredients, sizes and sides to match exactly what you serve, so the description is true for your dish.
