Comment ces exemples sont écrits

Uber recommande d'ajouter une description à vos articles, car elle aide les clients à choisir (informations à fournir pour votre menu). Uber ne fixe pas de longueur. Notre repère : entre 140 et 260 caractères, soit environ deux phrases courtes. Tous les exemples plus bas le respectent.

Chaque description dit ce qu'est le plat, cite ses ingrédients principaux, ajoute un détail qui vous ressemble et répond à une question avant qu'elle soit posée : la taille, le niveau d'épices ou ce qui est servi avec. Collez la vôtre dans notre vérificateur de description de plat gratuit pour contrôler la longueur et les mots.

Adaptez ces exemples à votre carte

  • Gardez le nom que vos clients connaissent, puis expliquez le plat.
  • Ne citez que les ingrédients vraiment présents.
  • Indiquez tailles, poids et nombre de pièces exacts.
  • N'écrivez végétarien, vegan ou sans gluten que si c'est vrai.
  • Évitez les mots vagues comme délicieux ou incroyable : les ingrédients en disent plus.

Questions fréquentes

Quelle longueur pour une description de plat sur Uber Eats ?

Uber ne fixe pas de longueur précise. Notre repère : entre 140 et 260 caractères, soit environ deux phrases courtes. Assez pour citer les ingrédients, assez court pour être lu sur un téléphone.

Que doit contenir une bonne description de plat ?

Ce qu'est le plat, ses ingrédients principaux, un détail qui vous ressemble, et ce que le client doit savoir avant de commander : la taille, le niveau d'épices ou ce qui est servi avec.

Reprendre ces exemples tels quels, c'est possible ?

Utilisez ces exemples comme point de départ. Changez les ingrédients, les tailles et les accompagnements pour qu'ils correspondent exactement à ce que vous servez, afin que chaque mot soit vrai.
